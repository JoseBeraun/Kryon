# T054 — Estados UX

Integrado en:

ListadoUsuarios.razor

## Sin permiso

Se muestra mensaje mediante role="alert" y TextosErrores.

## Lista vacía

No hay usuarios que mostrar

## Sin resultados

No hay usuarios que coincidan con la búsqueda y los filtros

## Error de red

No se pudo confirmar el resultado. Revisa el listado y vuelve a intentarlo.

Solo se captura HttpRequestException para ese estado.
