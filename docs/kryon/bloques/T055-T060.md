## Usuario de otra empresa

Debe ser indistinguible de un usuario inexistente.

Respuesta:

404

Esto aplica tanto a:

- desactivación;
- activación.

Cuando el usuario no sea accesible debe registrarse:

`UsuarioNoAccesible`

Datos permitidos:

- actor;
- empresa actual del actor;
- id solicitado;
- OperacionSolicitada;
- momento.

OperacionSolicitada:

- Desactivacion
- Activacion

No registrar:

- empresa propietaria del recurso;
- datos del recurso.

Referencia:

FR-046

## Sin capacidad
